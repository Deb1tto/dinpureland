Put photography images in this folder.

Recommended workflow:

1. Add image files here.
2. Run `npm run photos:sync`.
3. Edit `src/data/photos.json` to replace placeholder titles, dates, locations, descriptions, and notes.

Use web-friendly file names, for example:

```text
kyoto-evening-2025-12-17.jpg
lantern-wall-kyoto.webp
```
